# Asset PRO P0 — Experimental Data Area

**Status:** Experimental / Non-Normative

This directory is reserved for small Git-appropriate P0 artifacts such as:

- synthetic golden fixtures;
- small real golden fixtures;
- dataset manifests;
- expected fixture hashes.

Large historical validation datasets shall not be committed here by default. They must be referenced by immutable dataset identity, provenance, version, and checksum.

No P0 dataset has been frozen yet.
