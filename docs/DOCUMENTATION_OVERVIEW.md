# 4. Recommended Reading Order

New readers should start with the root [README.md](../README.md), then read [SPEC.md](SPEC.md), [ARCHITECTURE.md](ARCHITECTURE.md), and [DEVELOPMENT.md](DEVELOPMENT.md). Consult [ROADMAP.md](ROADMAP.md) for planned evolution and [DOCUMENTATION_STANDARD.md](DOCUMENTATION_STANDARD.md) whenever creating or modifying documentation.

# 5. Documentation Philosophy

Each document has a single primary responsibility. Information should be defined in the most appropriate document and linked from other documents rather than unnecessarily duplicated.

Documentation shall remain accurate, consistent, concise, versioned, traceable, and synchronized with implementation changes.
